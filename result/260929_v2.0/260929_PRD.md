# [반도체 159개 훈련과정 v2.0] PRD (요구사항 정의서)

## 1. 프로젝트 목적 및 핵심 변경사항 (v2.0)
- 목적: 딴딴's 반도체사관학교 159개 훈련과정 학습 대시보드를 사용자의 피드백에 맞추어 개편 및 GitHub Pages 온라인 배포
- 주요 변경 사항:
  1) 도해-글 순서 일치: 원문의 흐름 그대로 도해 - 설명 - 도해 - 설명 순서로 인라인 배치.
  2) CORE 프레임워크 전면 제거: 4개 요약 카드를 제거하고 원문 전체 읽기 및 인터랙티브 면접 질문에 집중.
  3) 분류 항목 영문 약어(Prefix) 적용:
     - 포토: [P]
     - 식각(에칭): [E]
     - 증착(박막): [D]
     - 이온주입: [I]
     - 확산/열처리: [T]
     - CMP/세정: [C]
     - 금속배선/패키징: [M]
     - 수율/공정제어: [Y]
     - 소자: [MOS], [SCE], [GAA], [DRAM], [NAND], [PWR]
     - 최신기술/기업: [HBM], [FND], [MKT]
  4) GitHub 온라인 배포: Git 저장소 연동 및 GitHub Pages를 통한 전 세계 어디서나 모바일/PC 접근 가능한 라이브 URL 제공.

## 2. 입출력 스펙
- 입력: `context/posts/*.json`, `context/post_catalog.json`, `context/images/*.png` (736개)
- 출력:
  - `result/260929_v2.0/index.html` (버전 아카이브)
  - `result/index.html` (로컬 배포본)
  - `index.html` (GitHub Pages 루트 배포본)
  - `tool/260929_v2.0/run.bat` (원클릭 재현 스크립트)
  - `deploy.bat` (원클릭 Git 배포 스크립트)
  - 온라인 라이브 URL: https://richvayne13.github.io/semiconductor-master/
