# [데이터 사전] YYMMDD_프로젝트명 원천 데이터 정의서

본 문서는 `context/` 폴더에 제공된 원천 데이터(Read-Only)의 무결성을 보호하고, AI 및 엔지니어가 데이터의 물리적 단위와 특성을 오인하지 않도록 사전에 정의한 데이터 딕셔너리입니다.

---

## 1. 파일 개요
- **파일명**: `example_raw_data.csv`
- **수집 일자 / 대상**: `2026-09-29 / 라인 1호기 인라인 검사기`
- **데이터 성격**: `인라인 검사 계측 시계열 데이터`
- **파일 포맷 / 인코딩**: `CSV / UTF-8 (또는 CP949)`

---

## 2. 컬럼 정의서

- `lot_id`
  - 설명: 생산 Lot 고유 식별 번호
  - 데이터 타입: String
  - 물리적 단위: 해당 없음
  - 유효 범위 / 제약: 10자리 영숫자
  - 결측치 처리: 결측 불가 (Drop 처리)

- `timestamp`
  - 설명: 계측 발생 일시
  - 데이터 타입: Datetime (`YYYY-MM-DD HH:mm:ss`)
  - 물리적 단위: 초 (s)
  - 결측치 처리: 결측 시 이전 행 값으로 보간(Forward Fill)

- `thickness_um`
  - 설명: 코팅 두께 측정값
  - 데이터 타입: Float
  - 물리적 단위: ㎛ (마이크로미터)
  - 유효 범위: 40.0 ~ 60.0 ㎛ (스펙 규격: 50.0 ± 2.0 ㎛)
  - 결측치 / 이상치 처리: 30 미만 혹은 70 초과는 센서 헌팅 노이즈로 마스킹

- `weight_mg`
  - 설명: 단위 면적당 전극 로딩 무게
  - 데이터 타입: Float
  - 물리적 단위: mg/cm²
  - 유효 범위: 18.0 ~ 22.0 mg/cm²
  - 결측치 처리: 중앙값(Median) 대체 또는 재계측 플래그 부여

- `defect_flag`
  - 설명: 비전 검사기 판정 결과 (0: 정상, 1: Burr 불량, 2: 미세라인 불량)
  - 데이터 타입: Integer
  - 결측치 처리: 기본값 0

---

## 3. 도메인 특이사항 및 노이즈 필터링 기준
1. **설비 헌팅(Hunting) 데이터**:
   - Lot 교체 후 초기 5개 샘플은 조건 안정화 구간이므로 분석 시 제외 처리.
2. **센서 포화치(Saturation)**:
   - 계측기 반감기/오프셋 틀어짐 발생 시 특정 고정값 반복 출력 여부 사전 스크리닝 필수.
