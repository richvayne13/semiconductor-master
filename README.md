# 반도체_2 | 누적형 소자·공정 심화 백과사전 & 면접 도감

SK하이닉스 양산기술(PE) 합격을 목표로, 반도체 학습 중 마주치는 난해한 소자/공정 개념을 **"1. 직관적인 일상 비유 & 1분 스피치"**와 **"2. 자체 설계한 정밀 풀컬러 SVG 도면"**의 2대 축으로 차곡차곡 영구 누적(Append)하여 단일 웹 대시보드로 보존·배포하는 공식 저장소입니다.

## 📌 핵심 운영 원칙 (사용자 지시 절대 가드레일)

1. **[⭐ 1, 2번 집중 설명 원칙]**:
   - 복잡한 3, 4, 5번(소자물리 상세 나열, 팹 공정 단계 나열, 전체보기)은 완전히 배제.
   - 오직 **[1. 핵심 요약 & 1분 스피치]**와 **[2. 정밀 도감 & 사진 해부]**로만 직관적으로 구성.
2. **[SK하이닉스 양산기술(PE) 정공법 일원화]**: 타 산업 접목 없이 순수 반도체 소자물리/팹 공정 관점 일원화.
3. **[초심자 직관 비유 선행]**: 물통, 수도꼭지, 쇠기둥, 바둑판 등 1초 만에 이해되는 일상 사물 비유 적용.
4. **[영구 누적(Append) 체계]**: 질의할 때마다 단일 대시보드에 토픽이 지속 축적되어 영구 보존됨.
